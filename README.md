# Citation Verifier

Citation Verifier is a deterministic research-integrity and academic verification platform designed to inspect research papers in PDF format. The system verifies whether bibliography references correspond to genuine scholarly records, validates metadata against trusted academic APIs, maps in-text citations to bibliography entries, and locally evaluates semantic alignment between claim contexts and cited abstracts.

## Problem Statement

Academic research frequently suffers from citation integrity issues, including:
- Non-existent or hallucinated citations generated by automated tools.
- Metadata mismatches (discrepant titles, misattributed authors, conflicting publication years, or erroneous DOIs).
- In-text citations mapped to incorrect bibliography entries.
- Superficial citations where cited works demonstrate negligible topical or contextual relevance to the claims they ostensibly support.
- Unsubstantiated conclusive assertions (overclaiming) lacking semantic backing in the cited literature.

Citation Verifier provides a transparent, explainable audit pipeline that separates verifiable bibliographic facts, calculated vector similarities, and heuristic review alerts without relying on external generative language models or opaque scoring algorithms.

## Key Features

1. **PDF Text & Bibliography Extraction**: PyMuPDF-powered machine text parsing with automatic reference section boundary detection and format support for IEEE numeric, APA-style, and standard numbered bibliographies.
2. **In-Text Citation Parsing & Mapping**: Sentence segmentation isolating citation markers (e.g., `[1]`, `[2, 4]`, `[3-5]`, and author-year formats) along with 3-sentence context windows mapped to target bibliography references.
3. **Scholarly Metadata Verification**: Deterministic validation querying Crossref REST API and Semantic Scholar Graph API using exact DOI matching and RapidFuzz token-sort similarity.
4. **Local Semantic Verification (Sentence-BERT)**: Local embedding generation using `sentence-transformers/all-MiniLM-L6-v2` to compute cosine similarity between citation contexts and retrieved paper abstracts without external cloud AI dependencies.
5. **FAISS Vector Indexing & Candidate Ranking**: Inner-product vector indexing ranking the cited reference against all bibliography candidates to identify potential citation misattributions.
6. **Transparent Multi-Component Scoring**: Explainable verification scores and relevance metrics with documented point breakdowns (DOI matching, title similarity, author match, and year consistency).
7. **Rule-Based Overclaim Heuristic**: Detection of assertive terminology (e.g., *proves*, *conclusively demonstrates*, *eliminates*) paired with semantic support evaluations to flag citations warranting human review.
8. **Interactive Citation Relationship Network**: SVG-based radial citation graph displaying paper-to-reference relationships color-coded by verification status.
9. **Dual Export Formats**: Instant download of comprehensive human-readable TXT audit reports and structured JSON analysis artifacts.
10. **Filesystem Persistence & Local Caching**: Complete data persistence in local filesystem directories (`uploads/`, `data/`, `cache/`, `results/`, `logs/`) without requiring an external database.

## Architecture

```
React Frontend (Vite)
       |
       | HTTP (REST)
       v
FastAPI Application Layer (backend/app/main.py)
       |
       +---> PDF Extraction (PyMuPDF)
       |
       +---> Citation & Reference Parser
       |
       +---> Metadata Verification Layer
       |        |---> Crossref REST API
       |        +---> Semantic Scholar Graph API
       |        +---> Local Filesystem Cache
       |
       +---> Local Semantic Layer
       |        |---> Sentence-BERT (all-MiniLM-L6-v2)
       |        +---> FAISS Vector Search Index
       |
       +---> Scoring & Heuristic Review Engine
       |
       +---> Filesystem Persistence (JSON Results & TXT Reports)
```

## Technology Stack

- **Backend**: Python 3.11+, FastAPI, Uvicorn, Pydantic v2, PyMuPDF, rapidfuzz, httpx.
- **NLP & Search**: sentence-transformers (`all-MiniLM-L6-v2`), PyTorch, FAISS (`faiss-cpu`), NumPy.
- **Metadata Sources**: Crossref REST API, Semantic Scholar Graph API.
- **Frontend**: React 19, Vite, JavaScript, CSS (vanilla academic design system), Lucide React.
- **Storage**: Local filesystem JSON/TXT persistence and SHA-256 keyed cache. No SQL/NoSQL database.

## Installation & Setup

### Prerequisites
- Python 3.11 (64-bit)
- Node.js v18+ and npm

### 1. Backend Setup
```bash
# Clone the repository
git clone https://github.com/v3ravani/Citation-Verifier.git
cd Citation-Verifier

# Create and activate Python virtual environment
py -3.11 -m venv venv
.\venv\Scripts\activate      # Windows
# source venv/bin/activate   # Linux/macOS

# Install backend dependencies
pip install -r backend/requirements.txt
```

### 2. Frontend Setup
```bash
cd frontend
npm install
cd ..
```

## Scoring Methodology

### Metadata Verification Score (100 Points Total)
- **DOI Exact Match**: 35 points (deterministic resolution)
- **Title Similarity**: Up to 40 points (token-sort ratio via RapidFuzz)
- **Author Match**: Up to 15 points (first author surname and token overlap)
- **Publication Year Match**: 10 points (exact or within +/- 1 year)

*Note: If no DOI was present in the extracted citation, points are proportionally redistributed: Title (55 points), Authors (25 points), Year (20 points).*

### Semantic Relevance Thresholds (Cosine Similarity)
- `>= 0.78`: Strongly related citation context
- `0.62 – 0.77`: Moderately related citation context
- `0.45 – 0.61`: Weakly related citation context
- `< 0.45`: Likely unrelated / potential misattribution

### Overall Citation Confidence Score
Calculated as a weighted combination:
`Overall Score = (0.55 * Metadata Score) + (0.45 * (Cosine Similarity * 100))`
*If the cited work's abstract is unavailable from scholarly APIs, the overall score is explicitly designated as Unavailable rather than fabricated.*

## Limitations & Disclosures

- **Semantic Similarity != Factual Truth**: High embedding similarity reflects conceptual or topical alignment, not experimental verification or factual correctness.
- **Abstract Scope**: Published abstracts summarize primary contributions; specific empirical figures or secondary methodologies cited in papers may not appear in abstracts.
- **Scanned Documents**: Version 1.0 requires machine-readable text; scanned image-only PDFs are detected and rejected with clear diagnostic guidance rather than simulated OCR.
- **API Availability**: External services (Crossref and Semantic Scholar) enforce rate limits and occasional maintenance downtime. When unavailable, errors are preserved honestly without guessing.
